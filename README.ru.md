# RSS

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/stezkoy/flarum-feeds.svg)](https://packagist.org/packages/stezkoy/flarum-feeds) [![Total Downloads](https://img.shields.io/packagist/dt/stezkoy/flarum-feeds.svg)](https://packagist.org/packages/stezkoy/flarum-feeds)

Расширение для Flarum 2.x, которое агрегирует RSS/Atom-ленты, показывает статьи независимых блогов на отдельной странице или в общем списке обсуждений на главной и позволяет пользователям создавать обычные темы Flarum из RSS-статей — только когда им нужно обсудить материал.

[Читать документацию на английском](README.md)

## Возможности

- Управление RSS/Atom-источниками в админ-панели.
- Модерация источников, добавленных пользователями, до их публикации.
- Привязка каждого источника к пользователю Flarum. Когда RSS-статья становится настоящей темой, этот пользователь указывается её автором.
- Предпросмотр источника в админ-панели с загрузкой ленты в реальном времени.
- Пустая строка внизу списка источников для быстрого добавления нового.
- Отдельная страница «Независимые блоги» со статьями из RSS.
- Опциональное перемешивание RSS-статей в список тем на главной по времени публикации.
- Кнопки на панели главной страницы для переключения между смешанным списком RSS и обычным списком тем, а также для подачи нового источника.
- Настройка для каждого пользователя: показывать ли RSS по умолчанию на главной.
- RSS-статьи не попадают в таблицу тем Flarum, пока кто-то не оставит комментарий.
- Виртуальная страница RSS-статьи до первого комментария с интерфейсом как у обычной темы.
- Тема создаётся лениво при первом комментарии и связывается обратно с RSS-записью.
- Настраиваемый тег назначается созданным из RSS темам.
- Статьи хранятся в отдельной таблице `rss_items`, чтобы не дублировать внешние материалы в списке тем до взаимодействия.
- Языковые файлы: английский, русский, китайский.

## Требования

- Flarum `^2.0.0-beta`
- PHP `^8.3`
- Composer

## Установка

Установка через Composer:

```sh
composer require stezkoy/flarum-feeds:"^3.0"
php flarum migrate
php flarum cache:clear
```

Включите расширение в админ-панели Flarum.

## Обновление

```sh
composer update stezkoy/flarum-feeds:"^3.0"
php flarum migrate
php flarum cache:clear
```

Если на форуме ещё установлено старое имя пакета, сначала переключите Composer-зависимость:

```sh
composer remove stezkoy/rss stezkoy/flarum-rss --no-update
composer require stezkoy/flarum-feeds:"^3.0" -W
```

## Настройка в админ-панели

Откройте страницу расширения RSS в админ-панели.

Доступные настройки:

- **Показывать RSS-статьи в списке на главной**: при включении статьи могут попадать в основной список на главной.
- **Тег для обсуждений RSS**: тег, назначаемый теме, когда статья конвертируется в настоящее обсуждение после первого комментария.

Таблица источников поддерживает:

- Редактирование названия и URL источника.
- Переключение статуса одобрения.
- Аватар привязанного пользователя, смену или отвязку пользователя.
- Предпросмотр источника в реальном времени.
- Удаление источника.
- Постоянную пустую строку для добавления следующего источника.

Источники от пользователей по умолчанию получают статус «На рассмотрении» и требуют одобрения администратора, прежде чем их статьи появятся публично.

## Использование на форуме

Когда режим RSS на главной включён глобально, на панели главной появляются:

- Кнопка переключения между смешанным списком RSS и обычным списком тем.
- Кнопка подачи нового источника, открывающая модальное окно.

Также на `/settings` у пользователей появляется раздел **RSS**. Переключатель **Показывать RSS-статьи на главной странице** управляет режимом главной по умолчанию:

- Вкл: главная по умолчанию показывает смешанный список RSS.
- Выкл: главная по умолчанию показывает обычный список тем.

## RSS-обсуждения и комментарии

RSS-статьи не вставляются в таблицу тем Flarum сразу после загрузки.

Вместо этого расширение хранит загруженные статьи в `rss_items`. В списке они выглядят как темы, но остаются отдельно, пока пользователь не прокомментирует.

До первого комментария:

- Счётчик комментариев ведёт на виртуальную страницу RSS-статьи.
- Страница использует интерфейс обычной темы Flarum.
- Первый пост содержит ссылку «Ссылка на оригинальную статью» на исходный материал.

После первого комментария:

- Создаётся настоящая тема Flarum.
- Назначается настроенный тег.
- Автором темы и первого поста становится привязанный к источнику пользователь.
- Комментарий пользователя сохраняется как обычный пост.
- Дальнейшие клики ведут в настоящую тему.

Это сохраняет базу форума чистой, но позволяет сообществу обсуждать RSS-материалы.

## Загрузка лент

Расширение регистрирует команду `rss:fetch`.

Загрузить все одобренные источники:

```sh
php flarum rss:fetch
```

Проверить один URL без сохранения:

```sh
php flarum rss:fetch "https://example.com/feed.xml"
```

Команда выполняется ежечасно через планировщик Flarum. Убедитесь, что на сервере запущен планировщик, например:

```sh
* * * * * cd /path/to/flarum && php flarum schedule:run >> /dev/null 2>&1
```

## Обновление со старых версий

Версии `3.0.0` и новее нацелены на Flarum 2.x и публикуются под именем пакета `stezkoy/flarum-feeds`. При обновлении с Flarum 1.x или со старого имени пакета сохраните существующие таблицы БД и выполните миграции (см. раздел «Обновление»).

Данные источников и статей переиспользуются версией для Flarum 2.x без потерь.
